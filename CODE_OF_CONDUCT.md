# Code of conduct

Applies to issues, pull requests and every other project space.

- Treat everyone with respect, whatever their experience, job or opinion.
- Criticize the code and the argument, never the person.
- No harassment, insults, discrimination, or exposing anyone's personal
  data.
- Do not post anyone's personal data (taxpayer IDs, addresses, contacts).
- Disagreements about a figure are settled by the official source and the
  measurement, not by opinion. Party politics stays out of the project.

Maintainers may edit or delete comments, close issues or pull requests, and
block anyone who breaks these rules. To report a problem, use GitHub's
"Report content", in the menu of the comment or issue.
